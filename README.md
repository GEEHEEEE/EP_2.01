# Кулинарная книга (RecipeBook)

Учебный проект по созданию десктопного приложения для ведения личной коллекции рецептов с генерацией списка покупок.

## Технологии
* **Язык:** Python 3
* **Интерфейс:** Tkinter (встроенный в Python)
* **База данных:** SQLite (встроенная в Python)

## Как запустить проект
1. Скачайте папку `recipe-app` из этого репозитория.
2. Убедитесь, что на компьютере установлен Python 3.
3. Откройте терминал в папке `recipe-app`.
4. Запустите главный файл:
   ```bash
   python main.py
